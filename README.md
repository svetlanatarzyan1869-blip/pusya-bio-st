# Цикл и беременность ꒰১ ໒꒱ — расширение SillyTavern

Плавающий кружок 🌸 в интерфейсе таверны → раскрывается в плашку состояния персонажа: цикл / течка-гон (омегаверс) / беременность / послеродовой период. Состояние считает **отдельная модель** (провайдер/ключ/модель задаются в ⚙ плашки) через вшитый Vercel-прокси и тихо влияет на отыгрыш основной модели.

Порт [Tavo-плагина](../pusya_bio) на SillyTavern. Общее ядро, тонкий слой под API таверны.

## Установка

1. В SillyTavern: **Extensions → Install extension**.
2. Вставь URL этого репозитория:
   ```
   https://github.com/svetlanatarzyan1869-blip/pusya-bio-st
   ```
3. После установки внизу справа появится кружок 🌸. Открой его, нажми ⚙ и заполни:
   - **Адрес провайдера** (base URL), **API-ключ**, **модель-считалку**;
   - режим (обычный / омегаверс), динамику (омега/альфа/бета), пол персонажа;
   - галочку «влиять на ролеплей».

## Что делает

- Плашка состояния: фаза, показатели, симптомы, советы, настроение.
- 📅 Календарь: проекция цикла/беременности/лохий на игровые даты. Дата берётся **из сюжета** (считалка читает историю), правится вручную.
- Влияние: состояние дописывается в промпт основной модели скрытым системным блоком (с учётом пола персонажа).
- Беременность (недели/триместры/ПДР) и послеродовой период (лохии ~6 недель → возврат к циклу).

## Отличия от Tavo-версии

- Игровая дата определяется только по выводу считающей модели (`date:`); отдельная скрытая метка в ответ основной модели не вставляется.
- Настройки — в `extension_settings`, состояние чата — в метаданных чата.

## Сборка

Не редактируй `index.js` вручную — он собирается из общего ядра:
```
python3 ../pusya_bio/build_st.py
```
(ядро — `pusya_bio/src/panel.js`, glue — `pusya_bio/st/header.js`)
